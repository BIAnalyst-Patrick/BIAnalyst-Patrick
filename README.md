## How I work

I work with **retailers, wholesalers and SMEs** on sales and financial
performance — the sales, margin and cash questions their owners actually decide on.

- **Find the cause, not the chart.** Every analysis starts from a decision, then
  decomposes the movement by store, category and segment to find where it sits.
- **Size every fix in gross profit.** Each recommendation carries an owner and an
  expected recovery, converted at margin, so a numbers person can argue with it.
- **Declare the limits.** Facts, hypotheses and genuinely unexplained findings are
  labelled separately. Where the data cannot answer, I say so rather than guess.
